Most definitions of intelligence measure the wrong thing.

Test scores, fluency, and recall all describe outputs, and every one of them can be high while real intelligence is low.

Here is the working definition I use for people, plans, and machines: intelligence is deciding and acting based on a profound understanding of cause and effect relationships. Judea Pearl called the layers of this the ladder of causation: seeing patterns, predicting interventions, imagining alternatives. A dashboard sits on the bottom rung. An A/B test sits on the second. A team that honestly asks "what would have happened if we had chosen differently" is on the third.

The definition changes how you evaluate AI. A language model that has read everything is still an association engine until it can act and observe the result. That is why an agent wrapped in a good test harness behaves so much more intelligently than the same model writing code it never runs: the feedback loop supplies the causal grounding that training data alone cannot. It changes how you evaluate proposals too. If nobody can state the causal claim in one sentence (we believe X causes Y, so doing Z should produce W), you have a pattern, not a plan.

Knowledge tells you what happened. Intelligence knows which lever to pull next, pulls it, and lets the world correct the model.
