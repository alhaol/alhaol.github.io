Put six top drivers in the same car and they qualify within a few tenths of each other. Put one driver in six different cars and the gap opens to whole seconds. Nobody in racing finds that confusing. In AI we still argue mostly about which model to use, and treat the harness around it (the loop that hands it tools, keeps its notes, and decides when the job is actually finished) as plumbing. The benchmarks now say that loop moves the result about twice as far as the model choice does, and it can change the cost of the same finished job by 40x. The awkward part is that no single harness wins everywhere. The best one shifts with the task, which makes this a routing problem rather than a standards problem.
