# My Prompts — a learning-accelerator library

Six copy-paste prompts that turn any chat AI into an active tutor: it asks before it tells, waits
for your reply, and won't hand over the answer until you've genuinely tried. Each prompt is a
standalone file you can open, fill in the `[BRACKETS]`, and paste into any model.

New here? Start with **[Guide.md](Guide.md)** — it explains the shared idea, which prompt to use
when, and how to chain them into a full learn → practice → verify loop.

## How to use

1. Open a file and copy the prompt inside its ```` ```text ```` block.
2. Replace every `[PLACEHOLDER]` (each file's **"Fill in first"** section says what goes where).
3. Paste into a fresh chat and play along — answer each question and wait. The value is in the loop.

> These were tuned for efficiency and accuracy: explicit AI role, hard "ask one question and wait"
> guardrails, clear stop/success conditions, and anti-cheat rules so the model can't shortcut the
> struggle that makes learning stick.
